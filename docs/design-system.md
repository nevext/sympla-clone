# Design System — Tokens Visuais da Sympla

Os tokens abaixo reproduzem os valores reais utilizados no tema da Sympla (`globals.css` e `src/styles/tokens.css.ts`).

## Paleta de Cores

### Brand (Azul Sympla)
| Token | Hex | Uso principal |
| :--- | :--- | :--- |
| `--color-brand-25` | `#f2f9ff` | Hover suave em categorias e cards |
| `--color-brand-50` | `#e5f4ff` | Fundo de badges e destaque de filtros |
| `--color-brand-200` | `#8acfff` | Bordas de foco e cards ativos |
| `--color-brand-500` | `#0097ff` | Botões primários, logo e CTAs |
| `--color-brand-600` | `#007fd6` | Hover de botões primários e datas nos cards |
| `--color-brand-700` | `#0063a5` | Textos de destaque em badges |
| `--color-brand-950` | `#012844` | Footer, Hero do produtor e cabeçalho do Ticket Box |

### Semânticas
- **Sucesso:** `#17b26a` (`--color-success-500`), `#079455` (`--color-success-600`), `#ecfdf3` (`--color-success-50`)
- **Aviso / Timer:** `#f79009` (`--color-warning-500`), `#fffaeb` (`--color-warning-50`)
- **Erro:** `#f03844` (`--color-error-500`), `#d9202d` (`--color-error-600`), `#fef2f3` (`--color-error-50`)

### Neutros
- **Gray:** `#fafafa` (`50`), `#f5f5f5` (`100`), `#e9eaeb` (`200`), `#d5d7da` (`300`), `#717680` (`500`), `#414651` (`700`), `#181d27` (`900`)
- **Slate:** `#eff1f5` (`100`), `#dcdfea` (`200`), `#b9c0d4` (`300`), `#141729` (`900`)

## Tipografia

- **Corpo (`--font-sans` / `--font-text`):** `Open Sans` (pesos `400`, `500`, `600`, `700`, `800`)
- **Títulos e Marca (`--font-display`):** `Raleway` (pesos `600`, `700`, `800`)

## Breakpoints

- `sm`: `360px`
- `md`: `768px`
- `lg`: `1280px`
